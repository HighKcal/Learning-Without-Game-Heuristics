# 모델 라이선스: MIT 적용

2026-10-14 사용자가 직접 학습한 원본 Checkpoint9개 전체에 별도 MIT를 적용하도록 승인했다. 저작권 표시는 Copyright (c) 2026 HighKcal이다. [MODEL_LICENSE.txt](../MODEL_LICENSE.txt)를 source와 Release에 제공한다.

수정·재배포·상업적 사용을 허용하며 model copyright·permission 고지를 유지한다. 무보증·책임 제한 조건도 적용된다. MIT에 없는 비상업·학술인용 의무를 추가하지 않는다. Source/document/fixture도 사용자 보유 권리 범위의 MIT이고, Native·외부 dependency의 고지를 덮어쓰지 않는다.

Phase4.5에서는 source/model 모두 MIT, model Apache-2.0 또는 CC BY4.0, 일부artifact만공개/특정파일보류를 비교했다. 최종 선택은 MIT와 원본9개 전체 공개이며 변환·대체는 실행하지 않았다. 코드·weights의 법적 성격과 저작권 성립을 동일하게 자동 단정하는 것은 아니다.

사용자 진술: pretrained/fine-tuning 없이 random initialization, 개인PC 학습, 환경에서 생성한replay. 현재 코드·payload가 이에 부합하며 외부 pretrained weights/data는 발견하지 못했다. 각 역사launch의 최초weights·완전sourceSHA/RNG는 미저장이므로 모든 출처를파일만으로증명하지 않는다. [승인 기록](RELEASE_APPROVALS.md)·[MIT 원문](https://opensource.org/license/mit)
